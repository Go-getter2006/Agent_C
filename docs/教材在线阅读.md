# C 语言教材在线阅读

当前教材向 C 语言课程的所有在册学生开放。知识问答右栏从章展开到最小小节，直接浏览 Word 原版转出的版面。点回答下的教材引用，只在右栏定位和高亮。高亮时间取对应回复的时间。

## 私有导入

教材发布者在私有目录保存 Word 原件、导出的 PDF 和阅读包。代码仓库只包含功能代码和虚构测试数据。

知识问答由回答模型直接理解提问，每轮读取本课程的最新学情和最近对话。有必要查阅教材时，模型从目录选一个或多个章节，并给出要查找的概念。程序在所选章节和下属小节内检索段落，模型据此回答并选择用到的引文。无需查书时直接回答。引文随回答保存。

1. 在有 Word 的电脑上把旧 `.doc` 另存为 `.docx`，从同一版本分别导出同名 PDF。总目录可补足正文中使用自动编号的标题。正文编号优先于较早的总目录。
   若原件带有整页底色，在用于导出的副本中将「页面颜色」设为「无颜色」。解析到章末习题标题后，题号和题目保留在习题正文里。
2. 在 `backend` 用项目 Python 环境生成阅读包。DOCX 按章节次序传入。PDF 放在单独的私有目录，文件名与对应的 DOCX 相同。总目录文件可选。

```sh
python -m app.cli textbook-prepare /private/c.textbook.private.zip \
  /private/word/第1章.docx /private/word/第2章.docx \
  --pdf-dir /private/pdf --contents /private/word/目录.docx
```

3. 将私有阅读包放到部署机器的私有目录，从服务端导入。应用通过现有数据库读取教材。

```sh
python -m app.cli textbook-import /private/c.textbook.private.zip
```

Docker 部署可在项目目录将私有包交给 Web 容器，导入后重建容器也能继续使用。

```sh
docker compose cp /private/c.textbook.private.zip web:/tmp/c.textbook.private.zip
docker compose exec web python -m app.cli textbook-import /tmp/c.textbook.private.zip
```

目录、切片和图片接口每次校验学生会话和课程，响应使用 `private, no-store`。网页按节只读展示，无原件下载或整本导出入口。在线显示过的版面仍可截屏。

## 原文引用

导入时从 Word 提取章节和原句。程序在同版 PDF 中找到文字位置后才纳入引用候选，图框对应可核对的 PDF 图片坐标。知识问答从已定位的片段检索，复用本轮已有的答疑请求。模型只能选择当前候选中的编号，无可靠候选时直接按通用知识答疑。问答记录保存已经核验的引用编号，替换教材版本后仍能找到当时引用的版本。

研究日志的教材字段只包含版本、小节和引用位置编号。

## 界面核对

采用 Wardline 的折叠目录和当前层级区分，参考 LocalCan 文档的独立阅读区域和路径提示。目录和版面放在知识问答已有配色的右栏，避免打开引文时移动对话。[Wardline，UI by Made Good Designs](https://madegooddesigns.com/inspiration/ui/sidebar-nav-web-minimal-81f555b73bbb) · [LocalCan 文档](https://www.localcan.com/docs)

使用实际 1 至 9 章在本地测试库核对了桌面右栏和窄屏抽屉。两名演示学生可阅读同一份资料。点引用后能看到对应句子或图框、回复时间，并保持聊天位置。退出登录后直接访问切片地址会被拒绝。答疑模型在本地验证使用测试替身。
