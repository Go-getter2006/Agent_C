# 对话、主动复习与题面分段修复

2026-11-18。此轮针对桌面端反馈，沿用项目现有 React、CSS、对话与小题接口。没有更改虚拟机或调用真实 DeepSeek、XDOJ。

## 交互

- 学生默认入口直接显示综合对话，删除原有学习首页组件与对应样式；题目深链接仍直接进入该题对话。
- 右侧资料栏从 420px 调整为 504px，增加 20%。原始 PDF 按钮移至右侧“题目”标题旁；侧栏抽屉里打开 PDF 时先关闭原抽屉。
- 修复左侧包裹层的 flex 高度链，题目列表在内部滚动；作业下拉菜单独立滚动。排序仍为未通过、未提交、已通过，保留上一轮业务规则。
- 复习页改为计划和历史，没有开始复习的操作门槛。到期小题通过普通对话消息呈现，可继续作答或跳过。

视觉参考采用 [Lumen Desk：UI by Made Good Designs](https://madegooddesigns.com/inspiration/ui/chat-ai-assistant-web-minimal-36fdca719589) 的对话与输入结构，并与此前 [Brilliant](https://brilliant.org/) 的学习入口参考对照。本轮以直接对话为主，不移植品牌素材、推广页或额外的仪表盘。

## 复习选择与时机

- 把有可靠诊断的未通过提交和后来改对的技能加入复习；卡住、复发、靠提示通过、小题答错等原规则仍保留。
- 对独立通过的题低频抽查：默认每累计十道不同的通过题，在本次为独立通过且该技能没有既有复习记录时可加入低优先级抽查。错误与不稳定项优先。
- 综合对话空闲时由前端自动请求 POST /api/threads/general/review。具体题目的对话不插题；学生正在输入、发送消息或最近两分钟发过消息时暂缓。
- 服务器复用尚未完成的复习题，PostgreSQL 部署按学生行锁串行处理并发请求；同一作答只附加一条消息。重复请求测试验证了复用，未开展多进程并发压力测试。
- 历史版本漏排的错误技能在活跃时限量补排：只查当前课程、可见题目、可靠诊断、近 180 天的最多 100 条候选，每半天最多补八个技能，不重置既有和已巩固的项目。
- 保留每日复习上限。修复“未完成题占住名额后，剩余名额被错误隐藏”的问题。页面把已生成的小题数称为“今天已安排”，不冒充已完成数。
- 出题器无法生成已验证题目时，保留该项并退避五分钟；不再宣称“今天不用复习”。对话明确显示小题暂未准备好，学生可以继续提问。

## 题面

- 识别样例输入/输出、输入/输出样例、输入/输出示例，以及编号、冒号、同一行数据和“样例说明”等变体。
- 样例说明、解释和提示结束样例块，使用普通正文换行，避免叙述文字进入横向滚动的代码块。
- 保留现有 PDF 文字层抽取与模型整理流程，不使用 OCR。模型提示明确要求区分输出说明、样例输入、样例输出和样例说明；程序核对样例数据的内容、顺序和分段。
- 现有文字会立即通过新前端分段器显示；本轮没有为全部旧题面重新调用模型。新进入整理流程的题面采用新约束；原始 PDF 可用于核对保留内容。

## 事实问答

明确的定义、语法、函数作用、参数含义和用法问题直接归入概念解答，不因为绑定了题目或助手刚刚问过问题就转为反问。

模型先给结论和必要解释，仅在确实相关时联系当前题目；不相关时不强行结合。调试“我的代码为什么错”与题意澄清仍分别处理。教学指导文件和提示版本同步更新，隐藏测试点保护继续保留。

## 验证范围

- 前端四项测试覆盖排序、时区、编号样例、同行样例数据和样例说明分离；TypeScript 与生产构建通过，更新 frontend/dist。
- Windows Edge 在 1440×1000 和 1280×1000 检查直接对话、自动小题、长题目列表、长作业菜单、504px 右栏、PDF 按钮位置及打开、样例与说明分段、无开始按钮的复习页。六组浏览器检查通过，无页面 JavaScript 错误和缺失的合成接口。
- 后端完整测试 195 项通过、20 项跳过，覆盖自动出题幂等、课程隔离、每日名额、出题失败退避、活跃对话暂缓、改正后的复习理由、历史补排、事实意图与样例保真。
- 本机测试使用合成数据与模型适配器替身。Windows 测试进程仅对 Linux resource 模块做导入替身；gcc/沙箱相关测试在本机跳过，不能据此声称已验证 Docker 沙箱或线上模型质量。

本机截图与浏览器记录保存在工作区 outputs/chat-review-update，不含真实学生数据。
