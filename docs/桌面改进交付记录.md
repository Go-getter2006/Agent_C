# 桌面改进交付记录

日期：2026-11-18。范围为桌面端；未开展手机端重新设计。后续按用户要求只读访问了虚拟机的网页、健康检查与公开登录说明接口，服务均可访问；SSH 未连通，未操作 Docker，也未调用真实 XDOJ 或真实 DeepSeek API。

## 用户提出的问题

- 切换作业时工作台不再先变成空壳，也不再自动经过最近题目的二次跳转。工作台保持挂载，保留已获取的作业列表；旧请求在作业切换或组件卸载后不能覆盖新选择。
- 左侧题目按未通过、未提交、已通过排序。已提交按最近提交时间倒序，未提交按题目编号升序；空时间排在同组有时间的记录之后。通过状态沿用原系统语义，未改变作业统计。
- 输入框下只保留键盘操作说明，删除“不直接给整题答案”的固定声明。
- 学生明确完全不会或请求局部代码示例时，可以进入示例帮助，不必先反复猜测。再次卡在同一处且明确要求示范时，不再强制先回忆、再挖空。帮助仍围绕局部困难，隐藏测试数据和课程隔离仍受程序校验。
- 教师桌面侧栏从 236px 缩为 184px。选中项自己绘制底色，关闭该项的颜色渐变，不依赖移动滑块到位后才可读；选中并悬停时也保留清晰文字。

## 首页与界面改进

- 学生默认进入轻量学习起始区：继续处理未通过的题、当前作业、到期复习；题目深链接仍直接进入原有对话。
- 教师总览将五项统计压缩为三项与一行状态。需关注的学生和共性问题、作业完成情况前移；趋势图和完整知识分布后移，长内容内部滚动。
- 登录介绍改为练习与引导的具体场景，修正即时同步承诺，按身份显示进入学习或进入教师工作台。
- 聊天左栏减少重复测试方块，右栏默认折叠之前的提交；保留完整提交页与代码对比。桌面正文与常规按钮统一阅读和操作规格。
- 教师图谱增加桌面章节导航，章节切换只改变视口与高亮，节点坐标和关系不变；可回到课程概览。原图表切换与跨课程权限保留。
- 五个 MCP 的真实参考与取舍见 [首页与 UI 细节复查](首页与UI细节复查.md)。

## DeepSeek 实际能收到什么

`chat/context.py` 从本地已同步记录构造上下文；`chat/reply.py` 通过 `llm.call_json` 发送模型请求：

| 内容 | 模型请求字段 | 条件 |
| --- | --- | --- |
| 题面 | 题目文本 | 本地已取到可用文字 |
| 学生完整源码 | 编号后的源码 | SourceSnapshot 已取到，或学生贴入代码 |
| 标准输入 | standardInput，附 testcaseId | 测试点输入已下载 |
| 标准输出 | standardOutput，附 testcaseId | 测试点输出已下载 |
| 学生实际输出 | programOutput，附 testcaseId、runId | 已取得对应评测运行的 RunOutput；不假装重新执行程序 |
| 编译诊断、结果、运行时间 | compileOutput、result、runTimeMs 等 | 已有对应评测记录 |

同一次评测中，程序的输入即该测试点的 standardInput。程序输出为空字符串表示已获取且确实为空；null 表示没有取到。请求额外携带可用性标记并要求模型承认缺失，不能将缺失输出推算成真实评测输出。只有缺少源码时才继续等待源码；其他详情没齐，不再阻挡对已有源码的讨论。

“字段能传入”不等于生产环境中每个字段都已经下载完成。本轮测试捕获了发送给模型适配器的消息，验证输入、标准输出、实际输出和源码都存在；没有使用用户虚拟机中的 API key 进行线上验证。

## 教学提示如何调整

默认教学指导在 `backend/app/chat/prompts/tutoring.md`，每一轮读取。可修改此文件，或设置 `CHAT_TEACHING_PROMPT_FILE` 指向自定义 Markdown 文件。Docker 使用自定义文件时，将它以只读 bind mount 挂到 web 容器，并让环境变量指向容器内路径。原有 JSON 协议、课程权限、隐私和隐藏测试点保护仍由程序执行。

模型还会收到学生最近的对话、代码、当前困难和帮助需求。可编辑提示用于教学方式；网络不可用时仍保留规则回退，不将模型连通性伪装为正常。
