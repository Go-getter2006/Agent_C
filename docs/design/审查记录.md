## 2. 对照禁止清单

### 视觉

| 条目 | 结果 | 说明 |
|---|---|---|
| 1 米色背景配衬线标题 | 通过 | 冷灰底、白色工作面，全部无衬线 |
| 2 渐变、发光、毛玻璃 | 通过 | 没有任何渐变和模糊 |
| 3 近黑背景配荧光色 | 通过 | 只有导航条是深色，上面只有浅灰字和黄色的当前项 |
| 4 同样的圆角卡片和柔和阴影 | 通过 | 没有阴影。层次靠三种底色和 1px 分隔线。唯一有边框的块是代码块和登录表单 |
| 5 圆角卡片加左侧彩色竖条 | 通过 | 被指出的代码行只用底色，没有色条 |
| 6 emoji 当图标、星星代表 AI | 通过 | 图标是 1.8 线宽的描边图标。智能体只用“智能体”三个字，没有头像和符号。回复里出现 emoji 会被校验拦下 |
| 7 居中大标题加三列卡片 | 通过 | 登录页只有一个表单；其余页面内容都是左对齐 |
| 8 花哨字体、全大写拉开字距的标签 | 通过 | 字重只有 400 和 600，没有全大写 |
| 9 等宽字体用在不是代码的小标签上 | 基本通过 | 时间、“第 3 次”等都是界面字体。教师端在技能名后面用等宽字体显示内部编码（如 `C06.03.02`），我把编码当作代码处理；你觉得不妥可以改回界面字体 |
| 10 链接后面加箭头、圆点拼元信息 | 通过 | 元信息都写成完整的短句，用逗号连接，如“已通过 3 题，共 7 题，11 月 29 日截止” |
| 11 淡入上滑、悬停动效 | 通过 | 只有抽屉出现时 0.16 秒的滑入 |
| 12 环形图、雷达图、大数字卡片 | 通过 | 学情页是列表、三段档位条和小方格；数字写在句子里。教师端的分布用横向分段条加一张数字表 |
| 13 无意义的插画、3D、库存图片 | 通过 | 没有任何图片 |
| 14 对比度不够的浅灰小字 | 通过 | 见上表 |

### 文案

| 条目 | 结果 | 说明 |
|---|---|---|
| 空洞口号 | 通过 | 登录页标题只有产品名 |
| “不是……而是……” | 通过 | 界面文案和模板回复里都没有 |
| 感叹号、说教、过度夸奖 | 通过 | 界面和模板里没有感叹号。答对了只说“改对了。”“判断对了。” |
| 按钮含糊 | 通过 | “发送”“登录”“运行检查”“重新发送”“现在做这道小题”“打开这道题”“立即同步名单和作业”“问问为什么错”。没有“提交”“确定” |
| 出错时说清楚发生了什么、怎么办 | 通过 | 例如“这次提交的代码还在取，稍等几秒再看。”“今天的小题已经做够了，明天再来。” |

### 反过来的套路

- 没有整齐地换成另一种默认样子：圆角是 4px 不是 0；等宽字体只用于代码；分隔线只用在栏与栏、行与行之间。
- 黄色只用于“当前选中”：导航当前项、当前题目行、作业选择器里选中的那一项。被指出的代码行和差异视图用的是另一个浅黄 `--mark`。教师端“试验中”的提示条也用了 `--mark` 底，这一处超出了规范写的用途，需要的话可以改成白底黑框。
- 绿和红只表示通过和未通过，并且和形状一起出现（实心格、空心格）。学情页“我的常见错误”的状态、小题结果前面的小方格沿用了同一套含义。教师端的四档分布没有用绿和红，用的是深色实心、灰、空心、浅灰。

## 3. 和原型不一样的地方

| 地方 | 原型 | 现在 | 原因 |
|---|---|---|---|
| 输入框 | 单行 | 默认一行高，贴代码时自动长高，最多约 8 行 | 贴代码需要多行 |
| 题目列表最后一行 | 没有 | “其他问题” | 见问题清单 |
| 右栏最新一次提交 | 一行字 | 多了一行格子和“问问为什么错” | 从这里也能直接问 |
| 手机题目头 | 只显示 | 点题目名换题，点下面那一行看这道题的情况 | 手机上没有左右两栏 |
| 代码块标题条 | 只有文字 | 右边有复制按钮 | 规范 4.6 允许 |
| 第一句话 | “比较那里没问题。看你这几行：” | 没配大模型时是“看你这几行：” | 模板不会针对学生的猜测回应，配了大模型后会 |

## 4. 已知的小问题

- 手机上小题的可编辑代码区能用，但输入法会挡住一部分；默认给的是选择题。
- 差异视图没有折叠相同的行，文件很长时要滚动。
- 教师端在手机上能看，但表格要横向滚动，主要还是给电脑用。
