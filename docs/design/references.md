# 参考

## 这一轮（界面重做）用了哪些参考

| 来源 | 怎么拿到的 |
|---|---|
| 你发来的四张图：法务检查的数据面板（深色侧边栏、指标卡、折线图、带状态标签的表格）、渐变落地页、威胁建模的连线图工具（点一个节点弹出详情）、KgBase 知识图谱（“选中相连的节点”筛选） | 直接看图 |
| 网页设计灵感站点、SaaS 数据面板的写法（Linear、Stripe、Vercel、Plausible 这类克制的面板）、知识图谱和网络图的交互写法 | 用搜索看了摘要。这个开发环境的网络代理不让打开这些站点本身（返回 403 或解析不了域名），**没有逐页打开核对** |
| 库道（DBEDU）的“按需获取学生查询日志”接口 | 只按你在消息里的描述（哪些 ID、什么时候、用了哪些样例、做了哪些交互）做；dbedu.tech 这个开发环境打不开，没有看到它的页面 |

只借鉴结构和交互思路，没有照搬任何一家的界面、配色和品牌元素。

| 借鉴了什么 | 用在哪里 | 没借鉴什么 |
|---|---|---|
| 深色侧边栏、白色药丸表示当前项、分组小标题 | 学生端、教师端的导航 | 侧边栏里的营销卡片、升级提示 |
| 一排指标卡，每张一个数加上和上周比的变化 | 教师端总览、模型对比 | 学生端的学情页没有用（见审查记录第 3 节） |
| 两张并排的趋势图：一张柱状、一张折线，各自一根纵轴 | 教师端总览、学生端每周提交、模型对比 | 双纵轴图；面积渐变填充 |
| 表格里用带图标的状态标签 | 提交、学生列表、卡点、日志申请记录 | 只靠颜色区分状态 |
| 图的画布可以拖动、缩放；悬停一个节点，它的邻居亮起来、其他变淡；点一下在右边打开详情 | 知识图谱 | 力导向布局（每次打开位置都不一样，老师没法记住“哪里是循环那一章”） |

| 上方一排筛选：课程、着色方式、搜索、显示方式 | 知识图谱 | 左侧一长列分面筛选（这里筛选项很少） |
| 节点和边的总数写在图旁边 | 知识图谱 | — |
| 图和表可以切换 | 知识图谱（读屏和打印时用表） | — |
| 申请时写用途、留审计记录、链接有有效期、可以撤销 | 日志申请 | — |

## 上一轮留下来的

| 参考 | 借鉴什么 | 不借鉴什么 |
|---|---|---|
| 代码托管平台的差异视图 | 两次提交并排、逐行对齐、改动的行整行上底色 | 红绿两色的增删标记：这里绿和红已经用来表示通过和未通过，所以改动用浅黄、删除用浅红 |

| 课程平台的学习进度页 | 按章节列知识点 | 环形进度、徽章、连续打卡天数、排名 |
