# 参考

说明：设计规范要求用 inspo、awwwards MCP、agent-browser 检索参考。这个开发环境里这三个工具都没有，所以下面是凭已有了解写的，**没有实际打开这些产品逐页核对**，只能当作起点。等有工具的环境再补一轮。

每条记“借鉴什么、不借鉴什么”。只借鉴结构和交互思路，没有照搬任何一家的界面和品牌元素。

| 参考 | 借鉴什么 | 不借鉴什么 |
|---|---|---|
| 代码托管平台的差异视图 | 两次提交并排、逐行对齐、改动的行整行上底色 | 红绿两色的增删标记：这里绿和红已经用来表示通过和未通过，所以改动用浅黄、删除用浅红 |
| 在线评测系统的提交列表 | 一行一次提交，结果用很短的词，测试点逐个列出 | 把每个测试点的输入输出展开给人看：学生不能看到测试数据 |
| 持续集成的状态格子 | 用一排小方格表示一组检查各自过没过，一眼看出是哪一个 | 悬停时弹出详情 |
| 代码编辑器的问题面板 | 点一条问题就定位到代码的那一行，那一行整行高亮 | 波浪线、图标、侧边色条 |
| 邮件和即时通讯里的“左列表、中间内容、右详情”三栏 | 列表选中项整行高亮；右边放当前对象的属性 | 头像、气泡、每条消息的时间戳 |
| 课程平台的学习进度页 | 按章节列知识点，每个一行 | 环形进度、徽章、连续打卡天数、排名 |
| 编程练习网站的选择题和填空题 | 题干短、代码块在题干下面、选项竖排 | 倒计时、得分动画 |
