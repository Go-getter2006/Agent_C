# 大模型调用核查（2026-11-21）

查三件事：每个调用大模型的地方，**读不读得到学生的问答**、**读不读得到题和输入输出**、**分析学生情况时有没有他的情况**。

怎么查：演示库 + 真实 DeepSeek，照学生的路径走一遍——作业引导里没过的题问错在哪、再接着问上一句；知识问答连问两句（第二句要接着第一句才懂）；没做的题问怎么做（流程图），选一步、再答一句；复习提升做一道小题（判断满足要求、被追问、坚持），看回顾，再提一个问题；已通过的题回头问。后台的几个（题目标注、看代码评“理解”、大改时对比两种做法）直接调一次。每次发给大模型的内容都记下来逐条看。`tests/test_llm_context.py` 把下面“现在”的内容锁住。

## 结果

|---|---|---|---|---|

另外几处：

- **学号姓名**：流程图引导、回头问、回顾、评“理解”的对话、对比两种做法，以前只去掉注释里像身份信息的内容，没按他的学号、姓名替换（他在消息里写了自己的名字就会发出去）。现在都按学号姓名替换。
- **回复结尾重复**：大模型常把“改完再交一次”在正文和结尾各写一遍，学生看到两句一样的。结尾那句和正文重复时去掉。
- **回顾作废太多**：要求 200 字以内，以前超一个字整段作废，退回“只列事实”。现在 260 字以内算合格，超了的重写时告诉它超了多少。
- 提示词版本改成 `2026-11-21b`（`config.PROMPT_VERSION`），分析时按版本分段。

## 实测（真实 DeepSeek，演示数据）

- 作业引导，接着问“你刚才说的那个地方，我是不是应该改成从第一个元素开始？”：回“对，`max` 的初值取第一个元素 `a[0]`，循环从 `i = 1` 开始比较”，接的是上一句说的初值。
- 知识问答，第二句“那读数组元素的时候呢？也要加吗”：回“要加……`scanf("%d", &a[i])`”，接的是上一句问的 `&`。
- 流程图第 2 步：引导点出“数组的定义和初始化”，问数组定义多大、怎么全置 0；他的学情里“数组的定义：待加强”在提示里。
- 复习小题（闰年条件 `||` 写错，他判断满足要求、被追问后坚持）：回顾说“你这次把三处全写成 ||，以前那次把三处全写成 &&，都是没分清‘同时成立’和‘满足其一’……你判断代码满足要求，说明还没抓住这个结构”。以前拿不到他的判断，只能泛泛地说。
- 看代码评“理解”：拿到题面和没过的测试点（2024、2000 都输出了 No），评“能解释”，摘的是他真改的那一行。
